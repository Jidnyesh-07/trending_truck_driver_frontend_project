ABOUT THE PROJECT

TruckBeats

A front-end music dashboard created for a truck-driver road-trip theme. It demonstrates responsive UI, JavaScript search, playlist selection and an interactive music-player interface.

Demo tracks use simulated playback. Replace them with audio files you have permission to use.
