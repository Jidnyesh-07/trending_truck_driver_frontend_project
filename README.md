# TruckBeats — Truck Driver Songs Website

A responsive truck-driver-themed music dashboard built with HTML, CSS and JavaScript.

## Features
- Featured road tracks
- Search tracks
- Interactive demo music player
- Next / previous / play controls
- Curated playlists
- Road moods and route cards
- Responsive mobile navigation
- Dark highway-themed interface

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Adding real audio
The player in this demo simulates playback. To use real audio, add audio files you have permission to use and connect them to an HTML5 `<audio>` element in `script.js`.
